# Local only tooltrace for Gridfinity

Hey, this is an actual public facing (UI friendly) port of my personal tooltrace tool for Gridfinity.
It allows you, from a photo, to have a trace of a tool that you'd like to create a gridfinity compatible bin for.

JPG / PNG are accepted (HEIC is a bit annoying, not working yet) at the time of writing.

This website works on mobile as well, the responsive interface is usable and the canvas is touch aware.

This was the playground for me to learn [Otsu's method](https://en.wikipedia.org/wiki/Otsu%27s_method) and to learn more about computer vision.
AI was definitely involved to correct things when I wasn't skilled enough to get them done first time / unblock myself and to get UI inspirations so I can make this thing usable by most.
